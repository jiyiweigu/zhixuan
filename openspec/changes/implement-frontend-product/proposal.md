## Why

产品书已经冻结用户端与管理端的页面、组件和交互要求，但当前前端只有首页骨架，队员无法按完整产品链路并行开发。需要先把产品书中的全部前端能力整理为一个可执行变更，统一路由、组件、状态、接口和验收边界。

## What Changes

- 实现 Vue 3 + TypeScript + Vite 单工程的用户端与管理端路由和布局。
- 实现首页、认证、档案、资格自检、问答、志愿方案、院校检索/详情/对比、收藏与历史页面。
- 实现管理端登录、知识库、索引、审核、途径规则和统计页面骨架。
- 建立来源卡、引用列表、置信度、免责声明、资格清单、方案卡、加载/空/错状态等公共组件。
- 接入统一 API 封装、Pinia 跨页状态、路由守卫和完整 Mock 状态。
- 保持编辑杂志风视觉：暖米色、柔黑、衬线标题、细边框、无阴影大圆角、响应式布局。

## Capabilities

### New Capabilities

- `frontend-product`: 覆盖产品书中全部用户端、管理端前端页面、组件、状态和交互验收。

### Modified Capabilities

- 无

## Impact

- 主要影响 `frontend/src/` 全部目录、前端依赖和构建配置。
- 依赖现有 API 契约、Mock 和后续后端接口，不改变后端业务规则。
- 页面必须遵守事实数据引用、免责声明和权限显示约束。
