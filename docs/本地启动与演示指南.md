# 本地启动与演示指南

> 目标：在一台 Windows 机器上把「智选志愿」前后端跑起来，走通从院校检索到 AI 问答、再到管理端的完整链路。
> 适用：本地演示、答辩彩排、队友联调。全部命令均在 **Windows + PowerShell / CMD** 下验证通过。

---

## 一、最快路径：双击一个文件

```
scripts\start-all.bat
```

它会依次做三件事：

1. 新窗口启动后端 FastAPI（`127.0.0.1:8000`）
2. 新窗口启动前端 Vite（`127.0.0.1:5173`）
3. 等 6 秒后自动打开浏览器

**关闭对应黑窗口即停止服务。** 首次运行前端若缺依赖，脚本会自动 `npm install`（可能需要几分钟）。

如果只想单独启动某一端：

| 脚本 | 作用 | 地址 |
|---|---|---|
| `scripts\start-backend.bat` | 只启动后端 | http://127.0.0.1:8000/docs |
| `scripts\start-frontend.bat` | 只启动前端 | http://127.0.0.1:5173 |

## 二、手动启动（两个终端）

### 1. 后端

```powershell
cd C:\Users\Administrator\Desktop\数媒大赛\backend
C:\Users\Administrator\.workbuddy\binaries\python\envs\zhixuan\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

看到 `Uvicorn running on http://127.0.0.1:8000` 即成功。

> 该虚拟环境已装好 `requirements.txt` 全部依赖。若要在自己机器上重建：
> ```powershell
> cd backend
> python -m venv .venv
> .venv\Scripts\activate
> pip install -r requirements.txt
> ```
> 之后把上面命令中的 python 路径换成 `backend\.venv\Scripts\python.exe` 即可（脚本会自动优先使用 `.venv`）。

### 2. 前端

```powershell
cd C:\Users\Administrator\Desktop\数媒大赛\frontend
npm install     # 仅首次
npm run dev
```

看到 `Local: http://127.0.0.1:5173/` 即成功。

### 3. 关键：前端必须关掉 Mock

`frontend\.env.local` **已经配置好**（该文件被 `.gitignore` 忽略，不会进仓库）：

```ini
VITE_USE_MOCK=false
VITE_API_BASE_URL=http://127.0.0.1:8000
```

> 判定逻辑是 `VITE_USE_MOCK !== 'false'` 就走 Mock。**只要这一行不是 `false`，页面里全是假数据，不连后端。**
> 改完 `.env.local` 必须重启 Vite 才生效。

## 四、建议演示动线（约 8 分钟）

按「一个问题从产生到被解决」的顺序走，比逐页点更讲故事：

1. **首页 `/`** —— 一句话说明产品：先看能报什么，再看能报哪、怎么填。
2. **院校库 `/schools`** —— 1367 所院校，按省份 / 层次 / 类型筛选，点进详情看画像与历年分数。
3. **专业库 `/majors`** —— 938 个专业，看选科要求与开设院校。
4. **注册 / 登录 → 考生档案 `/profile`** —— 填省份、选科、分数、位次、体检项（11 个字段，留空=未知，不默认合格）。
5. **资格自检 `/eligibility`** —— 演示四道闸门：
   - 省份规则（志愿数量 / 批次）
   - 选科（不满足 = 直接报不了）
   - 体检（不满足 = 报得上但会退档）
   - 学费 / 办学性质（提示项）
   重点讲结果三档：`eligible / blockers / warnings / unknowns`，规则缺失返回 `3001` 而不是静默放行。
6. **升学途径 `/pathways`** —— 26 类途径字典（P0 5 / P1 10 / P2 11），其中 10 类已接入目录、4 类可做路径资格自检；P2 如实标注「数据规划中」。
7. **志愿方案 `/plan`** —— 冲 / 稳 / 保三档推荐，展示分差、风险等级与数据来源。
8. **政策问答 `/qa`** —— 真实大模型 + 知识库检索，回答带 `[1][2]` 引用与置信度；问一个知识库没有的问题，会**明确拒答**而不是编造。
9. **管理端 `/admin`** —— 语料导入、规则维护、待审队列、索引重建，说明「AI 说的每句话都能追溯到来源」。

## 五、当前数据与能力现状（演示前心里有数）

本地库：`backend/.runtime/zhixuan.db`（SQLite，演示模式；生产为 PG16 + pgvector）。

| 表 | 行数 | 说明 |
|---|---:|---|
| `school` | 1367 | 院校主表 |
| `major` | 938 | 专业主表 |
| `school_major_score` | 116036 | 院校专业组历年录取分 |
| `score_segment` | 11694 | 一分一段 |
| `source` | 1641 | 数据来源台账（可溯源） |
| `pathway` | 26 | 升学途径字典（P0/P1/P2） |
| `subject_requirement` | 12507 | 选科要求（河南 2025 等） |
| `physical_restriction` | 992 | 体检限制（专业类级） |
| `knowledge_doc` / `knowledge_chunk` | 3 / 33 | 问答语料（**最小演示集**） |
| `admin_user` | 1 | 管理端账号 |

已知缺口（答辩时如实说明，反而是加分项）：

- **语料只有 3 篇 / 33 段**：问答仅覆盖已导入的河南/江西志愿规则，问其它问题会拒答。要覆盖更多政策，走管理端「语料导入」。
- `admission_requirement`、`major_tuition` 为 0 行：章程要求与学费闸门目前用演示值/提示态，不阻断。
- Embedding 仍是 `fake` 离线向量；接真模型的方法见 `backend/.env` 注释（`text-embedding-v3` 维度 1024）。
- 大模型已接通：`openai-compatible` + `deepseek-v4.1-flash`，实测问答可返回带引用答案。

## 六、常见问题

### 1. 端口被占用（`WinError 10048` / `EADDRINUSE`）

```powershell
netstat -ano | findstr :8000
netstat -ano | findstr :5173
taskkill /PID <上面的PID> /F
```

或直接换端口：后端 `--port 8001`，前端 `--port 5174`（同时改 `frontend/.env.local` 的 `VITE_API_BASE_URL`）。

### 2. 页面有数据，但全是假的 / 改后端没反应

`frontend/.env.local` 里 `VITE_USE_MOCK=false` 是否生效；改完必须重启 Vite（不是刷新浏览器）。

### 3. 浏览器控制台报 CORS 或 `Failed to fetch`

- 后端是否在 8000；`http://127.0.0.1:8000/api/health` 能否打开。
- 前端访问地址与后端 CORS 白名单一致（默认 `localhost:5173` 与 `127.0.0.1:5173`）。
- 本机若开了全局代理，把 `127.0.0.1` 加入代理绕过列表，或临时执行：
  ```powershell
  $env:NO_PROXY="127.0.0.1,localhost"
  ```

### 4. 问答总是「知识库暂无相关数据」

说明检索阶段没命中语料，不是模型坏了。检查 `knowledge_chunk` 是否有内容，或到管理端导入语料。当前最小集只覆盖河南/江西志愿规则。

### 5. 改了 `backend/.env` 不生效

`.env` 只在进程启动时加载。`--reload` 只监听代码文件变化，**改完请手动重启后端**。

### 6. 大模型 403 / `no access to model`

`ZHIXUAN_GENERATION_MODEL` 必须与 `{API_BASE}/models` 返回的 id **完全一致**（连字符、大小写、空格都算）。可用下面命令核对：

```powershell
curl.exe -H "Authorization: Bearer <你的Key>" https://api.toskaxy.xyz/v1/models
```

### 7. 前端首次 `npm install` 很慢

```powershell
npm config set registry https://registry.npmmirror.com
```
