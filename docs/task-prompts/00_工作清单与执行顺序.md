## 三、优先级说明（为什么是这个顺序）

1. **T1 最优先**：库里现在还是演示数据，T3/T8/T9 全都等真实数据。装载通道（importers）已入库，只差「仓库外整合产物 ↔ 导入层目录约定」一次对齐，是全清单里投入产出比最高的一项。
2. **T2/T3 是「创新 25 分」的支柱**：产品书 M3 知识库问答（可信机制：溯源 + 置信度 + 低置信入审核）目前是演示实现，`backend/app/rag/` 只有空 `__init__.py`。这是唯一整块未动的 P0。
3. **T4/T5 喂给 T6**：选科解析器其实已完整实现且 21 个自测全绿，只差「原始数据落位 + 落盘」；体检映射表是从零编写（产品自认最大价值点：体检不满足 = 报得上但会被退档）。
4. **前端可以今天就开始**：两个前端任务都只依赖契约 v1.4，不依赖后端进度（先 Mock 后接）。
5. **刻意不做**：学费数据（闸门④）——已决策延后；`main` 分支保护——不开。

## 五、协作规范（所有任务通用，各提示词里已内嵌）

- 提交 `type(scope): 中文描述`；分支 `chore/*` 或 `feature/*`，PR 合 `develop`（squash）；禁 `push -f`、`reset --hard`。
- 共享文件（`docs/api-contract.md`、`frontend/src/{api,types,mocks}`、`package*.json`、`docs/*.md`）只有队长可改——**模型改到这些文件时要在交付说明里单独列出改动点，等队长复核**。
- 数据红线：宁可缺、不可猜；`null` = 未填 ≠ 合格；规则缺失返回 3001。
- 仓库 Public + MIT：严禁提交密钥/隐私/未公开第三方数据（上海软科原始榜单已移出，别把它加回来）。
