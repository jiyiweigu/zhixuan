## 权威依据（每条规则必须有出处，这是「溯源」卖点的数据基础）

- 教育部、卫生部、中国残联《普通高等学校招生体检工作指导意见》（教学〔2003〕3 号）——**主依据**：其中「一、患有下列疾病者，学校可以不予录取」「二、患有下列疾病者，学校有关专业可不予录取」「三、患有下列疾病者，不宜就读的专业」三个清单，天然对应三个分级：
  - 第一部分 → **blocker**（可不录取：如严重心脏病、恶性肿瘤等——普适性，主要走档案核查，不映射专业类）
  - 第二部分 → **blocker**（**专业类映射的主体**：色觉异常不能录取化学类、医学类、生物科学类等；乙肝病原携带者不宜录取学前教育、航海技术、飞行技术等——以指导意见原文为准）
  - 第三部分 → **warning**（不宜就读：如色盲不宜就读生物技术、生态学等——**警告不拦截**，考生知情权）
- 《普通高等学校招生体检工作指导意见》的省级实施细则（河南/江西体检表项目：视力、色觉、身高、肝功能等）。
- 各校招生章程的常见附加限制（仅作补充示例，不逐校展开）。

## 任务要求

1. **产出文件**：`data/dictionaries/physical-restriction.json`，结构建议：
   ```json
   {
     "meta": {"source": "教育部教学〔2003〕3号《普通高等学校招生体检工作指导意见》", "source_url": "…", "compiled_at": "…", "notes": "…"},
     "rules": [
       {
         "rule_id": "PR-002-01",
         "condition": "色觉异常II度（色盲）",
         "condition_group": "色觉",
         "severity": "blocker",
         "major_categories": ["化学类", "医学类", "生物科学类", "…"],
         "basis": "指导意见第二部分第1条",
         "remark": "俗称色盲；色弱为II度以下，另条处理"
       }
     ]
   }
   ```
   覆盖条件族：色觉（色盲/色弱）、视力（裸眼远视力、矫正视力）、身高体重（军事/公安/师范类常见）、肢体运动、传染性疾病（乙肝携带者限报专业）、嗅觉/听觉、其他指导意见明列项。
2. **专业类口径**：用 `constraint_seed.py` 里 `MAJORS` / 契约里的专业类目（与 `major` 表 938 个专业的类字段对齐）；映射到**类**一级即可，不逐专业。
3. **分级铁律**：`blocker` = 「学校可不予录取」（报得上会被退档）；`warning` = 「不宜就读」（知情提示）；**绝不能把 warning 错标成 blocker**（过度拦截比漏拦更伤产品可信度），反之亦然。
4. **规模预期**：几百行量级（指导意见 3 个清单 + 专业类展开）。宁全毋缺，但**每条都必须能指回依据条款**——无依据的条目不写。
5. **引擎消费对齐**：字段名与 `engine/constraints.py` 闸门③期望的输入、`constraint_seed.py` 种子形状对齐；本任务**不改引擎代码**（那是 T6 的活），但要在 PR 里说明「T6 接入时按此格式读」。

### 关键设计决策（供评审）

1. **类级 vs 点名专业分开保留**：原文点名「X类各专业」→ `major_categories`（类级）；原文枚举具体专业 → `major_names`（专业级，**不上卷到类**）。反例说明：视力 5.0 条点名「飞行技术、航海技术、消防工程、刑事科学技术、侦察」分属 3 个类，若上卷到类会误伤「交通工程」「公安视听技术」等——上卷即过度拦截。**类级 + 专业级双清单同时入库**（专业级条目 `major_code` 非空，表已有联合索引）。
2. **乙肝条目政策更正**：任务书自查项要求「乙肝携带者限报为 blocker」，但 **2010 年教学厅〔2010〕2号已明确取消该限制条款与乙肝项目检测（保留 ALT）**。按「政策为准 + 不过度拦截」处理：保留在 `superseded` 区并附废止依据，不导入、不判档。慢性肝炎且肝功能不正常（ALT 超上限 2 倍口径，卫医政管便函〔2010〕76号）保留为 PR-2003-1-05（体检结论类）。
3. **军警标准纳入**（条件族「身高体重」）：军队依据《军队选拔军官和文职人员体检标准》（现行版男 162/女 158、BMI 区间、裸眼 4.5 线）、公安依据《公安院校公安专业招生体检标准》（2025 版男 170/女 160、BMI、裸眼 4.8、色弱色盲、耳语听力 5 米）。军校/公安条件加后缀「（军队院校）/（公安院校）」——**禁用于普通批次判档**（军检警检单独组织）。
4. **engine_ready 开关**：原 14 条引擎扩展项中，T6 已支持 4.5 裸眼视力线；当前仍有 13 条因 BMI 区间、性别维度、矫正度数或档案缺字段需要保留 unknown。清单在 JSON meta 与导入包 manifest 中双份留档。
5. **宁缺不猜**：军队色觉条款原文未核到（PR-ARMY-05 占位不导入）；师范类身高无国家统一标准（属院校章程事项，不录）——均在 meta 注明。
6. **离线可复跑（追加提交）**：生成器初版 `main()` 无条件读仓库外整合产物 `merged/major.json`，该文件不在仓库内、缺失即崩——与「院校库之所以准予入库」同一条红线。已改为「`data/majors/majors.json` 为必需基线 + 仓库外产物可选并入」。**先验后改**：两源对 93 个专业类、12 个「门类→类展开面」逐项一致，本字典引用的 44 个类 / 4 个门类 / 79 个点名专业解析零差异；重跑产出 sha256 `ddd23749a9a7cb42` 在「外部在机（938 专业）/ 不在机（845 专业）」两场景完全相同、且与改前逐字节一致（`physical-restriction.json` 零改动）。
