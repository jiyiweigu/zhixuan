## 二、口径（红线）

### 2.1 scope：首期只做本科批

依据队长《数据源与数据获取方案》与产品书「首期只做本科批」：

- **专科批全部排除**。原因：`data/schools/schools_merged.json` 是
  **在豫招生的 1367 所本科院校**，**不含专科院校**，专科行的 `school_id` 无法挂上。
- 实测专科命中率：河南 12.9~13.2%、江西 4.2% ⇒ 排除是正确决策，不是丢数据。
- 排除时**逐条记录跳过原因**（`skipped` 统计），不静默丢弃。
- 提供了 `--keep-prep` / `--keep-art` 开关，如需提前批/艺术类可显式打开。

### 2.2 `batch` 必须保留

⚠️ **不得合并批次**。本科一批/本科二批的批次线不同、投档序列不同，
合并会丢失批次线信息（同 `score_segment` 的口径）。

### 2.3 `subject_type` 口径断裂

| 省份 | 老高考（文理科） | 新高考（3+1+2） |
|---|---|---|
| 河南 | ≤ 2024：`文科` / `理科` | ≥ 2025：`物理类` / `历史类` |
| 江西 | ≤ 2023：`文科` / `理科` | ≥ 2024：`物理类` / `历史类` |

必须用 `subject_type` + `exam_system` 双重标记，**不得跨考试制度比较**。

### 2.4 `admit_count` ≠ `plan_count`

- `admit_count`（实际录取数）来自录取表；
- `plan_count`（招生计划数）来自 `enrollment-plan.csv`。

**本表不混填**：`plan_count` 留在计划表，避免口径污染。`admit_count` 作为
辅助字段留存（第 7 章无此列，供 ② 参考）。

### 2.5 `max_score` 不落库

第 7 章 `school_major_score` **无 `max_score` 字段**，且原始数据中 `max_score`
几乎全表为空（见 §4.3），故**不落库**。

### 4.4 ★ 未匹配 `school_id` 的根因（重要）

未匹配行 = 院校库中**没有对应院校**。根因有三类：

**① 院校改名**（主要）

院校库取自**河南 2026 招生计划**，而录取分是 **2022–2025**。期间多所院校改名：

| 录取分旧名 | 教育部名单现名 | 国标码（一致） |
|---|---|---|
| 湖州师范学院 | **湖州师范大学** | 10347 |
| 绍兴文理学院 | **绍兴大学** | 10349 |
| 榆林学院 | **榆林大学** | 11395 |
| 皖南医学院 | **皖南医科大学** | 10368 |
| 滨州医学院 | **山东第二医科大学** | 10438 |
| 防灾科技学院 | **应急管理大学** | 11104 |
| 合肥学院 | 合肥大学 | ✓ 已核 |
| 赣南医学院 | 赣南医科大学 | ✓ 已核 |
| 桂林医学院 | 桂林医科大学 | ✓ 已核 |
| 海南医学院 | 海南医科大学 | ✓ 已核 |
| 佛山科学技术学院 | 佛山大学 | ✓ 已核 |
| 福建工程学院 | 福建理工大学 | ✓ 已核 |
| 赤峰学院 | 赤峰大学 | ✓ 已核 |

> ⚠️ **本脚本不做自动改名推断**（会把「XX学院」误猜成「XX大学」，风险高）。
> 改名映射已**逐条核实后**单独维护于 `data/schools/school_aliases.json`，
> 生成脚本 `data/scripts/build_school_aliases.py`，详见 **§4.6**。

**② 军事院校**：`91xxx` / `92xxx` 代码，不列入教育部普通高校名单，**匹配不上是正确的**。

**③ 独立学院 / 分校区**：如 `北京理工大学珠海学院`、`复旦大学上海医学院`、
`华北电力大学(北京)` vs `(保定)` 等，名称书写差异。

### 4.5 归一化处理（已实施）

仅做**确定无歧义**的归一化：
- 全角括号 → 半角
- 去空格
- 反复剥离尾部括号（`X(原Y)` → `X`）取**核心名**兜底

**不做**改名推断。

### 4.6 ★ 院校改名别名表（已实施，`school_aliases.json`）

**问题**：院校库取自 **2026 河南招生计划**，录取分覆盖 **2022–2025**，期间改名院校无法按名匹配。

**解法**：`data/scripts/build_school_aliases.py` 生成 `data/schools/school_aliases.json`，
数据来源**两条，均不靠推断**：

| 来源 | 条数 | 说明 |
|---|---:|---|
| ① 院校库**自身内联**的 `新名(原旧名)` 标注 | 44 | 正则 `^(.+?)\(原(.+?)\)` 从 `schools_raw.json` 提取 |
| ② 教育部《全国普通高等学校名单》逐条核实的名校改名 | 28 | 现名必须**在`moe_schools.json`中真实存在**，否则剔除并告警 |
| 合并去重后 | **72**（其中 48 条能映射回 1367 院校库） | 24 条现名仍不在库内（如湖州师范大学/绍兴大学/榆林大学，库未收录） |

**导入时的映射优先级**（`import_major_score.py` 内，任一命中即停）：

1. 河南：`university_code.zfill(4)` → 河南招生代号索引
2. `university_name` → 全名/归一化名索引
3. `code2name[code]` → 校名索引（江西等自编代号省）
4. `alias.resolve(name)` → 现名再索引（`match_via="alias"`，可追溯）
5. 核心名（剥离尾部括号）兜底

**效果**：未匹配 2,862 行（2.5%）→ **1,983 行（1.71%）**，救回 1,184 行。

**剩余未匹配（1,983 行）原因分布**：院校库外 28 个 / 独立学院 22 个 / 军事院校 3 个 /
疑似数据脏值 2 个（`了喀什大学`、`和豫章师范学院`，首字异常，**不猜测不修补**）/ 分校区 1 个。
明细见 `data/schools/school_aliases.json` 的 `no_match_reason` 与 `stats` 段。

## 五、给 ②（后端）的接入提示

1. **建表**（M0-3，② 负责）：`school_major_score` 字段见产品书第 7 章。
2. **`school_id` 为空的行**：这是**客观缺失**（院校库无此校），
   导入时应保留并打 flag，**不要拒绝**，前端呈现时提示「院校信息待接入」。
3. **`subject_type` 为空（2024 两省）**：需 ② 确认下游能否容忍空科类。
4. **`data_status` 全为 `pending`**：渠道来源，未逐条对官方核实。
   逐条核实通过后才可升 `available`（**L2 试点核实是拿奖关键**）。
5. **`year` 取值**：首期 2022 / 2024 / 2025（2023 无可用数据）。

  --kind school_major_score
