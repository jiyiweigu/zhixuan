## 六、★ 数据源可采集性验证结果（2026-10-11 实测）

使用 `curl` 实测各源连通性与防护情况（`--noproxy '*'`，模拟浏览器 UA）：

| # | 数据源 | URL | 实测 HTTP | 判定 |
|---|---|---|---|---|
| 1 | **河南省教育考试院** | https://www.haeea.cn/ | **412** | ❌ **有 JS 挑战型 WAF** |
| 2 | 河南招生考试信息网 | https://www.heao.com.cn | **412** | ❌ 同样 WAF |
| 3 | 教育部阳光高考 | https://gaokao.chsi.com.cn/ | **412** | ❌ 同样 WAF |
| 4 | **河南省阳光高考信息平台** | https://gaokao.haedu.cn/ | **200** ✅ | ✅ **可直接抓取** |
| 5 | 河南省教育厅 | https://jyt.henan.gov.cn | **200** ✅ | ✅ 可直接抓取 |

### 6.1 关键发现：412 是 JS 挑战型 WAF

对 `haeea.cn` 的 412 响应体做了分析，返回内容为：

```html
<meta id="qAx7NxyxCzEz" content="..." r='m'>
<script>$_ts=window['$_ts'];...$_ts.cd="qxmJrrQlEaQqDq33r..."</script>
```

**这是典型的瑞数（RiverSecurity）类 JS 挑战防护**，特征：
- 返回混淆的 JS 代码，需**浏览器内核执行**后才下发真实内容
- `$_ts.nsd`、`$_ts.cd` 是动态生成的挑战参数

**已验证：仅加完整浏览器请求头（UA/Accept/Sec-Fetch 等全套）仍然返回 412** —— 说明它检测的不是请求头，
而是**浏览器环境指纹与 JS 执行能力**。

### 6.2 影响与对策

| 源 | 影响 | 对策 |
|---|---|---|
| haeea.cn / heao.com.cn / chsi.com.cn | ⚠️ **无法用 requests/httpx 直接抓** | 方案 A/B/C（见下） |
| gaokao.haedu.cn | ✅ 可抓 | 直接 `requests` + `bs4` |
| jyt.henan.gov.cn | ✅ 可抓 | 直接 `requests` + `bs4` |

**方案 A（推荐，最稳）**：用**无头浏览器**（Playwright / Selenium）驱动真实内核，可自动通过 JS 挑战。
- 优点：稳定、通用
- 缺点：需装浏览器内核（约 150MB），速度慢于纯 HTTP

**方案 B（合规优先）**：人工下载官方发布的 **PDF/Excel 附件**，脚本只负责解析。
- 优点：完全合规、稳定、不触发风控
- 缺点：需人工介入
- 💡 官方数据多以附件形式发布，**这条路径反而最贴合实际**

**方案 C（需确认）**：降低频率 + 完整浏览器指纹，试探是否能过。
- ⚠️ 不推荐作为主方案，且**须先问队长是否允许**

> **建议组合**：核心政策文件（一分一段、控制线）走**方案 B 人工下载 + 脚本解析**；
> 需要批量采集的院校信息走**方案 A 无头浏览器**。

### 6.3 ⚠️ 合规提醒

对这些网站采集前**必须先向队长确认**：
1. 是否允许自动化采集？采集频率上限？
2. 是否需要遵守 `robots.txt`？
3. 采集是否会触发风控导致 IP 被封（影响其他队员）？

> 参赛作品涉及数据采集，**合规性会被评审关注**。建议在文档中如实说明采集方式。
