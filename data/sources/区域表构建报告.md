| 表字段 | 本文件字段 | 说明 |
|---|---|---|
| `id` | （入库时自增） | 主键 |

| `county_name` | `county_name` | 县名 |

| `source_id` | `source_id` | 关联 `source` 表 |

- `city` / `category` / 三要素为**附加字段**，供人工核对与校验使用，入库时可选。
- 校验：

```bash
python data/scripts/validate.py data/dictionaries/pathway-regions.json --kind pathway_region
```
