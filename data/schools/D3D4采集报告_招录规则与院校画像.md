## 二、D3 · `enrollment_rule`

### 2.1 ★ 数据源与语义边界（务必先读）

**本轮不采招生章程原文**（章程需逐校抓官网，已试点验证不可行，见 §5）。
实际做法：从 **Gaokao-Compass 招生计划数据集**的专业级字段**聚合**出院校级要求：

| 目标字段 | 源字段 | 说明 |
|---|---|---|
| `subject_req` | 招生计划 `subject_req` | 原文取值 + 频次，**不做归一**（避免失真） |
| `health_req` | `major_note`（体检类） | 按优先级归类为 色盲色弱 / 色盲 / 色弱 / 色觉异常 / 视力 / 乙肝 / 听力 / 身高 |
| `foreign_lang_req` | `major_note`（语种类） | 归一为语言名（英语/日语/俄语…） |
| `content` | `major_note`（其余限制） | 主要为**性别要求** |

> ⚠️ **语义边界**：专业备注是**专业级**的（「某专业不招色盲」），聚合到院校级会失真
> （「该校不招色盲」≠ 事实）。因此每条产出的文本**强制带「仅部分专业（N 个），非全校统一要求」限定**，
> 并附频次。**绝不表述为全校统一要求。**

### 2.2 字段覆盖率（2,615 行）

| 字段 | 有值 | 占比 |
|---|---|---|
| `subject_req` | 2,365 | **90.4%** |
| `foreign_lang_req` | 1,023 | **39.1%** |
| `health_req` | 578 | **22.1%** |
| `content`（性别等） | 46 | 1.8% |

年份分布：**2023 = 250、2024 = 1,119、2025 = 1,246**。

### 2.3 为什么只有 2023–2025？

源数据本身如此（本科批非空行数）：

| 文件 | `subject_req` | `major_note` |
|---|---|---|
| 2022 河南 / 江西 | 0 | **0** |
| 2023 河南 | 0 | **0** |
| 2023 江西 | 0 | 7,412 |
| 2024 河南 | 0 | **0** |
| 2024 江西 | 23,939 | 5,624 |
| 2025 河南 | 34,001 | 18,520 |
| 2025 江西 | 0 | **0** |

→ 老高考年份（河南 ≤2024、江西 ≤2023）**无选科概念**，`subject_req` 为空属**制度性缺失**，非采集失败。

### 2.4 产出样例

```
【适用范围】仅部分专业（14 个），**非全校统一要求**
【体检要求】色盲色弱（14 个专业）；色盲（3 个专业）
【来源】河南省教育考试院 / 江西省教育考试院 普通高校招生计划（专业备注）
```

```
【覆盖】该校 2025 年在 河南、江西 招生计划共 31 条记录
【选科要求取值（原文·频次）】化（19）；不限（10）；政（1）；生（1）
【来源】河南省教育考试院 / 江西省教育考试院 普通高校招生计划（专业备注）
```

### 2.5 来源归因

依 `source-table.json` 中 `SRC-GAOKAO-COMPASS` 的 `plan` 字段要求
（「作品内事实结论的 source_url 须指向省考试院/阳光高考，**不指向本数据集**」）：

- `source_id` = `SRC-GAOKAO-COMPASS`（获取渠道，链路可追溯）
- `source_url` = 省考试院（河南 `haeea.cn` / 江西 `jxeea.cn`），按记录主源省份择一
- 记录另带 `_source_channel` 字段记录实际分发渠道（透明）

## 三、D4 · `school_profile`

### 3.1 字段来源分层

| 字段 | 来源 | 等级 | 覆盖率 |
|---|---|---|---|
| `tuition_range` | 招生计划 CSV `tuition`（本科批）按校聚合 min-max | **官方** | **97.3%**（1,273） |
| `established_year` | 校官网「学校简介/概况」页正文 | 高校官网 | 52.4%（686） |
| `faculty_count` | 同上（教职工/专任教师） | 高校官网 | 44.8%（586） |
| `first_class_major_count` | 同上（国家级一流本科专业建设点） | 高校官网 | 23.2%（303） |
| `campus_list` | 同上（校区名，仅列举结构） | 高校官网 | 9.2%（120） |
| `master_phd_points` | 同上（博士/硕士学位授权点） | 高校官网 | 6.3%（83） |
| `student_faculty_ratio` | 同上（生师比） | 高校官网 | 0.5%（6） |
| `accommodation_fee` | —（官网简介页不载） | — | **0%** |

### 3.2 口径要点

- **`tuition_range`**：数值**直出**，排除 `0`（1,411 条 = 未定/占位）。区间形如 `5000-14000`；
  同值时为单值 `4590`。记录附 `_tuition_stats`（min/max/median/样本数/年份/省份）供复核。
  → 跨 4 年两省聚合，因学费全国统一、且 `school_profile` 为**一校一行**。
- **官网字段**：正则抽取**忠实原文、不做推断**，抽不到即留空。已做区间合理性过滤
  （建校年份 1850–2026、师资 100–30,000 人、一流专业 1–300）。
- **`campus_list`**：初版用滑窗 `{2,4}校区` 产生大量污染（「括黄河路校区」「作科学城校区」），
  改为**仅在列举结构中抽取**（「现有A校区、B校区」/「A校区、B校区」相连），覆盖率降但质量可控。
  仅含校区名，`address`/`city` 留空。
- **`student_faculty_ratio` 极低（0.5%）**：949 份简介页中仅 **7 份**写了生师比 —— 属**源本身稀缺**，
  非正则问题（已实测确认）。

## 四、D4 · `school_life`（仅官方来源）

| category | 行数 | 说明 |
|---|---|---|
| 校园环境 | 670 | 占地面积 / 建筑面积 |
| 图书馆 | 241 | 馆藏纸质图书 |

- 911 行 / 覆盖 **544 所**院校，`reliability` **全部 = `official`**（前端无需折叠）。
- 抽取模式**强制以「数字+单位」收尾**（`占地…亩` / `建筑面积…万平方米` / `馆藏…万册`），
  否则会跨表格单元拼接出无意义串（实测污染：「科生 4623 硕博研究生总占地面积 1.44 万亩」）。

### ★ 未产出部分（如实留空）

| category | 官网简介页命中率 | 处理 |
|---|---|---|
| **宿舍** | 8% | ❌ 不产出（多为「公寓管理先进单位」类噪声，非生活描述） |
| **食堂** | 2% | ❌ 不产出（同上） |
| **交通** | — | ❌ 无有效承载 |

**宿舍 / 食堂 / 交通**这三类**核心生活信息**，官网简介页承载极少。
需走**非官方来源**（论坛/自媒体，产品书 7.3 设计上允许 `reliability=unofficial` 并前端折叠）
或各校**后勤服务网**（入口深、覆盖率低）。
→ 前者涉及**内容合规与来源可信度**，须 ④/⑤/队长定策略；后者**已试点验证不可行**（见 §5）。
**本轮不作臆测填充。**

## 五、为什么不做「招生章程」逐校采集（试点结论）

试点 12 所院校，从官网首页 → 招生入口 → 找「章程」链接：

| 结果 | 数量 |
|---|---|
| 找到「章程」链接 | 6 |
| 其中**真·招生章程** | **2**（上海建桥学院、上海中侨职业技术大学） |
| 其中**「大学章程」**（学校治理文件，语义完全不同） | 4（三峡大学「大学章程」、上海中医药「学校章程」、上海大学「上大章程」、上海健康医学院「学校章程」） |
| 无招生入口 / 页面失败 | 6 |

→ 真章程命中率仅 **~17%**，且**极易误抓「大学章程」**（这是**严重**的语义错误）。
**结论：逐校采集章程不可行**，`enrollment_rule.content`（章程正文）与
`school_profile.accommodation_fee` 本轮**如实留空**，需另立专项（如统一从阳光高考平台获取）。

## 六、★ 关键发现：院校库覆盖缺口（独立于本轮，但影响匹配率）

D3 / D4 聚合时未能挂上 `school_id` 的招生计划行：

| 指标 | 数值 |
|---|---|
| 未匹配行数 | **4,589**（本科批，占 1.3%） |
| 涉及院校数 | **297** |
| 未匹配行中占比最高的院校 | 大连理工大学城市学院（255 行）、闽江学院（203）、江西警察学院（198）、重庆三峡学院（197）、湖州师范学院（169） |

**根因**：这些院校**根本不在院校库（1,367 所）中**，而非名称匹配算法问题。
其中一批是 **2026 年更名院校**，教育部名单（`moe_schools.json`，2,952 所）里已是新名：

| 招生计划（源）用名 | 教育部名单现名 |
|---|---|
| 闽江学院 | **闽江大学** |
| 湖州师范学院 | **湖州师范大学** |
| 重庆三峡学院 | **重庆三峡科技大学** |

**影响面**：院校库缺口会**同时拉低**所有事实数据的院校匹配率（录取分 / 招生计划 / 本轮 D3·D4）。
**建议**：另立任务重跑院校库采集（`fetch_schools.py` + `merge_schools.py`），
或从 `moe_schools.json` 补录缺失院校 —— 属**独立于 D3/D4** 的工作，本轮未动。
