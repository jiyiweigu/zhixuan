## 二、⚠️ 重大发现：找到了可直连的官方源（推翻原有判断）

**原判断**（`采集验证报告.md`）：`haeea.cn` / `heao.com.cn` / `chsi.com.cn` 均为
**412 瑞数 JS 挑战 WAF**，批量采集需上 **Playwright 无头浏览器**（需站会申报依赖）。

**新发现**：河南省阳光高考信息平台的**招生计划查询系统**是**独立子域**，
**传统 ASP.NET WebForms + JSON AJAX** 架构，**无任何 WAF**：

| 用途 | 接口 |
|---|---|
| 院校列表页 | `https://zsjh.haedu.cn/qwerasd/school` |
| **院校数据（JSON）** | `https://zsjh.haedu.cn/qwerasd/dyna-school?page=<n>` |
| 院校详情 | `https://zsjh.haedu.cn/qwerasd/beth/<院校代号>` |

> ✅ **纯 HTTP GET 即可拿到结构化 JSON** ⇒ **零新增依赖，无需 Playwright**。
> 这解决了 `采集验证报告.md` 第 5 节"需要批量采集的院校信息走方案 A 无头浏览器"的依赖申报问题。

**发现路径**：招生计划页用 `<iframe>` 加载 → 找到 `zsjh.haedu.cn` 子域 →
从页面内联 JS 读出 AJAX 接口 `dyna-school` 与分页参数。

## 三、数据来源（双源交叉）

### 源 A：河南阳光高考 · 招生计划查询系统
- **URL**：`https://zsjh.haedu.cn/qwerasd/school`
- **source_id**：`SRC-HENAN-ZSJH`
- **提供**：在豫招生院校清单、教育部国标代码、批次、科类、院校代号
- **接口字段**：`YXMC`(校名) `YXDH`(河南代号) `school_national_code`(国标码)
  `YXSF`(省份码) `PCMC`(批次) `KLMC`(科类) `JHZS`(计划数)
- **分页**：`page=0..83`，每页 30 条，共 2495 条

### 源 B：教育部《全国普通高等学校名单》
- **URL**：`https://hudong.moe.gov.cn/qggxmd/`
- **source_id**：`SRC-MOE-SCHOOL-LIST`
- **接口**：`GET /school/wcmdata/getDataIndex.jsp?listid=10000101&page=<n>`
- **提供**：学校名称、10位标识码、主管部门、所在地、层次
- **分页**：`page=1..148`，每页 20 条，共 **2952 所**（全国本科 1412 / 专科 1540）
- **关键**：10 位标识码的**后 5 位** = 国标院校代码（北大 `4111010001` → `10001` ✓）

## 四、合并与推断逻辑

### 4.1 匹配（merge_schools.py）

| 方式 | 数量 | 说明 |
|---|---|---|
| 国标代码精确匹配 | 1316 | 首选 |
| 院校名匹配 | 20 | 代码缺失时兜底 |
| **未匹配** | **31** | **全部为军事院校**（见下） |

**31 所未匹配全部是军队院校**（代码 `91xxx`/`92xxx`，如国防科技大学 `91002`）：
军队院校**不列入教育部普通高校名单**（属军队系统），**匹配不上是正确的，不是数据缺失**。

### 4.2 `ownership` 推断（已交叉验证）

教育部名单的「主管部门」字段取值本身即区分公办/民办：

| 主管部门形态 | 判定 | 验证样本 |
|---|---|---|
| `河南省`（裸省名） | **公办** | 郑州大学、河南大学 ✓ |
| `教育部` / 中央部委 | **公办** | 北京大学、清华 ✓ |
| `河南省教育厅`（省+教育厅） | **民办** | 黄河科技学院、郑州升达经贸管理学院 ✓ |
| `河北省教育厅` | **民办（独立学院）** | 河北大学工商学院 ✓ |

结果：**公办 935 / 民办 345**，87 所无法判定（31 军校 + 未匹配）→ 留空，**不猜**。

### 4.3 省市解析（踩坑记录）

教育部名单的「所在地」有两种形态：
- 带省前缀：`河北省石家庄市`
- **仅市名：`保定市` / `石家庄市`**（直辖市 `北京市`）

⚠️ 最初把「市」也当省级后缀 → `保定市` 被误当省名。已修正：省级后缀只认
`省 / 自治区 / 特别行政区`；仅市名的记录，`province` 由**源 A 的院校省份**（河南考试院口径）回填。

## 六、口径偏差说明（需队长确认）

**任务 2.1 原文**：「入库约 300 所本科院校」

**实际采集**：在豫招生的本科院校共 **1367 所**（普通本科批 1300 所）。

**分析**：河南是高考大省，"在豫招生的本科院校"包含**全国范围**的本科高校，
1300+ 是真实全量。任务描述的"约 300 所"可能是：
1. 只指**河南省属**本科（约 60 所）
2. 只指**主流/常用**院校的子集
3. 估计偏保守

**当前做法**：**保留全量 1367 所**（对院校检索功能更有价值），
并在输出 `meta` 中标注口径。**待队长确认**是否需要收窄。
