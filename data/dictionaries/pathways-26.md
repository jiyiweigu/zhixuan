## 一、字段说明（对齐契约与第 7 章）

`GET /api/pathways` 要求每项含 `id`、`name`、`status`、`category`、`priority` + 来源三要素；  
第 7 章 `pathway` 表字段为 `id, name, category, batch, target_group, apply_time, description, priority, data_status, source_id`。

**本文档字段以此为并集**：

| 字段             | 含义                                    | 取值说明                                               |
| -------------- | ------------------------------------- | -------------------------------------------------- |
| `id`           | 途径唯一标识                                | 用英文短横线小写，如 `national-special`                      |
| `name`         | 途径名称                                  | 中文正式名称                                             |
| `category`     | 类别                                    | 见下方「类别枚举」                                          |
| `batch`        | 录取批次                                  | 如「本科提前批」「本科批」「专科批」                                 |
| `target_group` | 面向人群                                  | 简要描述                                               |
| `apply_time`   | 申请/报考时间节点                             | 一般在高考后的哪个阶段                                        |
| `priority`     | 建设优先级                                 | `P0` / `P1` / `P2`                                 |
| `data_status`  | 数据状态                                  | `verified`（有来源）/ `schema_only`（仅架构）/ `pending`（待采） |
| `status`       | 界面可用状态                                | 与 `data_status` 联动，供前端展示                           |
| 来源三要素          | `source_name` / `source_url` / `year` | **缺一不得入库**                                         |

### 类别枚举（建议，待 ② 确认）

```
专项计划     国家专项、地方专项、高校专项
普通录取     普通批、提前批
特殊类型     强基计划、综合评价、保送生、高水平运动队、高水平艺术团
艺术体育     艺术类、体育类
军警司法     军校、公安、司法、消防
公费定向     公费师范、优师专项、免费医学定向、定向培养军士
民族与边疆   少数民族预科、民族班、支援中西部协作
职教通道     高职单招、对口升学、专升本
其他         中外合作办学、港澳高校、留学
```

## 三、⚠️ 关于"26 类"的说明（需与队长确认）

上面第 26 项凑满了 26，但**这是我按政策常见分类整理的建议版**。有两点必须澄清：

1. **"26 类"的具体口径来源不明** —— 产品书 M2-1 写"途径字典接口 + 列表/详情页（26 类）"，  
   但**未给出这 26 类的清单**。我这份是按高考升学政策常见类型整理的**候选集**。
2. **可能有重复或遗漏** —— 例如「对口升学」「专升本」是否算入升学途径（它们不通过普通高考）；  
   「港澳高校」「出国留学」是否纳入。这些取决于产品定位。

## 四、P0 三类的资格判定字段映射（重点）

这三类需要真实数据 + 规则，是 M2 的核心。规则条件必须与**档案 12 字段**对齐：

### 4.1 国家专项计划（`national-special`）

| 规则类型 | 规则描述                 | 用到的档案字段                                | 数据需求                         |
| ---- | -------------------- | -------------------------------------- | ---------------------------- |
| 区域   | 户籍在实施区域的县            | `household_county`                     | **38 县名单**（`pathway_region`） |
| 户籍   | 本人具有当地连续 3 年以上户籍     | `household_type`、`household_years`     | 阈值规则                         |
| 学籍   | 户籍所在县高中连续 3 年学籍并实际就读 | `enrollment_county`、`enrollment_years` | 阈值规则                         |
| 监护人  | 法定监护人户籍在当地           | `parent_household_local`               | 布尔规则                         |

### 4.2 地方专项计划（`local-special`）

| 规则类型 | 规则描述          | 用到的档案字段                             | 数据需求     |
| ---- | ------------- | ----------------------------------- | -------- |
| 区域   | 户籍在本省农村（省定区域） | `household_type`、`household_county` | 省级实施区域名单 |
| 户籍   | 农村户籍          | `household_type` = `农村`             | 枚举判定     |

### 4.3 高校专项计划（`college-special`）

| 规则类型 | 规则描述                | 用到的档案字段                                | 数据需求            |
| ---- | ------------------- | -------------------------------------- | --------------- |
| 区域   | 户籍在边远/贫困/民族地区       | `household_county`                     | 实施区域名单（较国家专项更宽） |
| 户籍   | 本人及监护人户籍在农村且当地满 3 年 | `household_type`、`household_years`     | 阈值规则            |
| 学籍   | 当地高中连续 3 年学籍并实际就读   | `enrollment_county`、`enrollment_years` | 阈值规则            |

> ⚠️ **注意字段名差异**：契约用 `household_county`/`enrollment_county`，  
> 第 7 章 `user_profile` 表用 `home_county`/`school_years` —— **两者需对齐**，请 ② 确认以哪个为准。
